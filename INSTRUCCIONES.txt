PARCHE CORREGIDO - INFORME DE QUIEBRE ACUMULADO <= $4.99
===========================================================

REGLA DEFINITIVA
----------------
QUIEBRE = saldo desde $0.00 hasta $4.99 inclusive.

El quiebre comienza cuando el cliente entra a $4.99 o menos.
El quiebre termina cuando vuelve a $5.00 o mas.

Ejemplo:
  10:00  $8.00   -> fuera de quiebre
  14:00  $4.50   -> comienza quiebre
  18:00  $3.00   -> sigue en el MISMO quiebre
  08:00  $1.00   -> sigue en el MISMO quiebre
  11:00  $7.00   -> termina quiebre

El tiempo acumulado seria desde las 14:00 hasta las 11:00 del dia
siguiente. Los cambios dentro de $0.00-$4.99 NO crean quiebres nuevos.

1) SUPABASE
-----------
Abre Supabase > SQL Editor > New query.
Copia TODO el contenido de:

  06_INFORME_QUIEBRE_MENSUAL.sql

y pulsa Run.

IMPORTANTE:
Si ya habias ejecutado la version anterior que usaba $0.00,
NO PASA NADA. Ejecuta este SQL corregido y reemplazara la funcion
anterior con la regla <= $4.99.

No borra el historico ni modifica el agente.

2) WEB
------
Copia:
  quiebre-report.js

dentro de:
  web\

Si ya existe una version anterior, REEMPLAZALA.

3) INDEX.HTML
-------------
Al final de web\index.html debe quedar:

  <script src="./app.js?v=24"></script>
  <script src="./quiebre-report.js?v=2"></script>

Si habias puesto ?v=1, cambialo por ?v=2 para evitar cache.

-----------------

5) INFORME
----------
El informe mensual mostrara:
- Clientes que estuvieron en <= $4.99.
- Horas acumuladas de quiebre.
- Cantidad de entradas a quiebre.
- Quiebres que venian desde el mes anterior.
- Mayor periodo continuo en quiebre.
- Recuperaciones: cuando vuelve a >= $5.00.
- Saldo al cierre del mes.
- Casos >=24h, >=48h y >=72h.
- Exportacion CSV.
- Impresion / PDF.
